# 心象 - 设计思考

## 气质与意象

**关键词**：禅意、新拟物、宣纸触感、东方神秘

**具象场景**：
晨光透过窗棂落在一方宣纸上，纸面温润，字句如墨痕浮起。这里没有霓虹与数据流，只有柔和的光影凹凸——元素像被指尖轻按过的软陶，自纸面悄然隆起。这不是严肃的命理推算，而是给当代人的一处静心之所：在生辰与心象之间，用温润的算法陪你观照自己。

## 视觉策略：新拟物 (Neumorphism)

- **核心手法**：元素与背景同色，靠「左上高光 / 右下暗影」的双向阴影从背景凸起；输入框、被选中态、内嵌槽位用 `inset` 阴影呈现凹陷。
- **不用边框、不用发光**：层次完全由凹凸阴影建立，避免一切霓虹、渐变光晕、强对比描边。
- **触感优先**：按钮按下时从凸起切换为凹陷（`.neu-press:active`），模拟实体按键。

## 配色方案：暖调宣纸 + 国风点缀

| 用途 | 颜色 | CSS 变量 | 意象来源 |
|------|------|----------|----------|
| 背景 | 宣纸米白 | `--neu-bg: #e8e3da` | 宣纸、素绢 |
| 暗影 | 暖灰 | `--neu-dark: #c3bcae` | 右下投影 |
| 高光 | 近白 | `--neu-light: #fdfaf3` | 左上受光 |
| 正文 | 墨色 | `--neu-text: #4a443b` | 浓墨 |
| 次要文字 | 淡墨 | `--neu-text-muted: #968e7f` | 淡墨晕染 |
| 点缀·主 | 黛青 | `--neu-cyan: #3f7a78` | 黛、青瓷 |
| 点缀·辅 | 黛紫 | `--neu-purple: #6f5d92` | 紫毫 |
| 点缀·暖 | 绛朱 | `--neu-pink: #a85761` | 朱砂、绛 |
| 点缀·土 | 赭石 | `--neu-amber: #9a6f3c` | 赭石 |

点缀色保持低饱和，仅用于关键信息（分数、五行、宜忌、标题），不大面积铺色。

## 工具类（定义于 `src/app.css`）

- `.neu-page`：页面底色
- `.neu-raised` / `.neu-raised-sm`：凸起面（卡片 / 小元素）
- `.neu-pressed` / `.neu-pressed-sm`：凹陷面（输入 / 选中 / 槽位）
- `.neu-press`：可按压态，按下切换为凹陷
- `.neu-fg` / `.neu-muted`：墨色 / 淡墨文本
- `.neu-cyan` / `.neu-purple` / `.neu-pink` / `.neu-amber`：国风点缀色文本

## 字体排版

- **标题**：`font-bold` + 较大字间距（`tracking-[0.15em~0.3em]`），营造郑重、留白的东方气韵
- **正文**：`leading-relaxed`，保持舒适阅读
- **数据**：八字天干、四柱用 `font-mono`，呈命盘表格感
- **节奏**：标题 → 副题（淡墨小字）→ 凸起卡片组 → 底部留白提示

## 文案气质：禅意 + 传统神秘

- **基调**：温润含蓄、有古意，可化用「心、象、气、神、月、水、风、云」等意象，但自然不晦涩、不堆砌。
- **品牌词**：产品名「心象」；概念词统一为「今日心象 / 心象命盘 / 心象偈语」。
- **关键改写示例**：
  - 启动 → 「叩问今日心象」
  - 排盘 → 「录入生辰」「排我的心象命盘」
  - 收藏 → 「珍藏 / 收录」
  - 重新生成 → 「重新推演」
  - 祝福语 → 「偈语」（如「心象清明，如月印千江」）
- **安全声明**：统一为含蓄表述「所言仅为遣怀清心，非关休咎/决断」，严禁绝对化、恐吓式文案（如「大凶、务必、必」）。

## 设计禁忌

**明确禁止**：
- ❌ 霓虹发光、青紫渐变、数据流/赛博意象（已整体弃用）
- ❌ 边框描边 + 强对比建立层次（层次只靠凹凸阴影）
- ❌ 大面积高饱和色块
- ❌ 绝对化、恐吓式文案
- ❌ 过度阴影导致脏污浑浊（阴影需柔和、克制）
- ❌ 用 View/Text 手搓通用交互组件（输入框/开关/弹窗仍优先用 `@/components/ui/*`，仅外层套新拟物容器）

## 差异化检查

- 把产品名遮住，仅凭描述能认出吗？→ 暖调宣纸新拟物 + 禅意文案的东方玄学应用，与霓虹赛博风、与传统命理 App 都截然不同。
- 是否出现「科技蓝 + 圆角卡片 + 蓝紫渐变」万能组合？→ 没有，整体为单色宣纸凹凸 + 国风低饱和点缀。
