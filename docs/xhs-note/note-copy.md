## 正文（可直接粘贴）

忙到没空想「我到底什么感觉」的时候，
我更想要的不是答案，
是一张今天的心象。

「心象」是一个可点开的小工具：
录入生辰 → 看今日签卡 → 想聊就去问心。

你可以每天回来看看：
· 今日之象（一句心境）
· 宜 / 忌（当倾向，不当指令）
· 色 · 数 · 向（意象锚点）
· 保存签卡长图，留给自己或发朋友

说在前面：
所言皆为遗怀清心之趣，
非关休咎，不作决断之凭。
不是算命，是自我观察。

数据只存在你的本机，不联网、不上云。

👇 点这篇笔记里的小工具就能直接体验
喜欢的话收藏一下，明天再来叩问一次～
